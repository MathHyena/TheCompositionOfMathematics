    Section 1.6 Functions

    Remark 1.6.1. Prerequisites.

    Familiarity with sets from Section 1.4 and relations from Section 1.5.
    🔗
    🔗

    Remark 1.6.2. Learning Objectives.

    By the end of this section, the reader should be able to:
    🔗
    • define a function as a special type of relation;
      🔗
      🔗
    • distinguish domain, codomain, and range;
      🔗
      🔗
    • interpret function notation and mapping notation;
      🔗
      🔗
    • evaluate functions and determine equality of functions;
      🔗
      🔗
    • recognize identity, constant, inclusion, and piecewise-defined functions;
      🔗
      🔗
    • determine whether a function is injective, surjective, or bijective;
      🔗
      🔗
    • compose functions and interpret the order of composition;
      🔗
      🔗
    • understand inverse functions and the connection between invertibility and bijectivity;
      🔗
      🔗
    • work with images and preimages of sets;
      🔗
      🔗
    • interpret sequences and multivariable functions as functions;
      🔗
      🔗
    • recognize common errors involving functions.
      🔗
      🔗
    🔗
    🔗

    Subsection 1.6.1 Why Functions Matter

    Functions are among the most central objects in mathematics.
    🔗
    They describe how one quantity, object, or structure depends on another.
    🔗
    Examples include:
    🔗
    • the area of a circle as a function of its radius;
      🔗
      🔗
    • position as a function of time;
      🔗
      🔗
    • temperature as a function of location;
      🔗
      🔗
    • probability as a function of an event;
      🔗
      🔗
    • a matrix transformation acting on vectors;
      🔗
      🔗
    • a derivative assigning a new function to a differentiable function;
      🔗
      🔗
    • a statistical model mapping data to predictions.
      🔗
      🔗
    🔗
    Nearly every branch of mathematics uses functions in some form.
    🔗
    🔗

    Subsection 1.6.2 Functions as Special Relations

    Recall that a relation from \(A\) to \(B\) is a subset of
    🔗
    \begin{equation*} A\times B. \end{equation*}
    🔗
    A function is a relation with an additional requirement.
    🔗

    Definition 1.6.3. Function.

    A function \(f\) from a set \(A\) to a set \(B\) is a relation that associates each element of \(A\) with exactly one element of \(B\text{.}\)
    🔗
    🔗
    Thus every input must have one and only one output.
    🔗
    🔗

    Subsection 1.6.3 Function Mapping Notation

    A function from \(A\) to \(B\) is commonly written
    🔗
    \begin{equation*} f:A\to B. \end{equation*}
    🔗
    The arrow
    🔗
    \begin{equation*} \to \end{equation*}
    🔗
    is read
    🔗
    “maps to”
    🔗
    in this context.
    🔗
    Thus,
    🔗
    \begin{equation*} f:A\to B \end{equation*}
    🔗
    is read
    🔗
    “@@PROTECTED0@@ maps @@PROTECTED1@@ to @@PROTECTED2@@”
    🔗
    or
    🔗
    “@@PROTECTED0@@ is a function from @@PROTECTED1@@ to @@PROTECTED2@@.”
    🔗
    The same arrow has different readings in other contexts. For example, \(x\to a\) in calculus is read “@@PROTECTED1@@ approaches @@PROTECTED2@@.” Context determines the intended meaning.
    🔗
    🔗

    Subsection 1.6.4 The Mapsto Symbol

    The symbol
    🔗
    \begin{equation*} \mapsto \end{equation*}
    🔗
    is called the mapsto symbol and is read
    🔗
    “maps to.”
    🔗
    For example,
    🔗
    \begin{equation*} x\mapsto x^2 \end{equation*}
    🔗
    means that the input \(x\) is assigned the output \(x^2\text{.}\)
    🔗
    A complete description may be written
    🔗
    \begin{equation*} f:\R\to\R,\qquad x\mapsto x^2. \end{equation*}
    🔗
    🔗

    Subsection 1.6.5 Function Notation

    If \(f\) is a function and \(x\) is an input, the corresponding output is written
    🔗
    \begin{equation*} f(x). \end{equation*}
    🔗
    This is read
    🔗
    “@@PROTECTED0@@ of @@PROTECTED1@@.”
    🔗
    The parentheses do not mean multiplication.
    🔗
    Thus,
    🔗
    \begin{equation*} f(x) \end{equation*}
    🔗
    does not mean
    🔗
    \begin{equation*} f\cdot x. \end{equation*}
    🔗
    🔗

    Subsection 1.6.6 Domain

    Definition 1.6.4. Domain.

    For a function
    🔗
    \begin{equation*} f:A\to B, \end{equation*}
    🔗
    the set \(A\) is called the domain of \(f\text{.}\)
    🔗
    🔗
    The domain is the set of allowed inputs.
    🔗
    It may be written
    🔗
    \begin{equation*} \dom(f)=A. \end{equation*}
    🔗
    🔗

    Subsection 1.6.7 Codomain

    Definition 1.6.5. Codomain.

    For a function
    🔗
    \begin{equation*} f:A\to B, \end{equation*}
    🔗
    the set \(B\) is called the codomain of \(f\text{.}\)
    🔗
    🔗
    The codomain is the set in which the outputs are required to lie.
    🔗
    It may contain elements that are never actually produced by the function.
    🔗
    🔗

    Subsection 1.6.8 Range or Image

    Definition 1.6.6. Range.

    The range, or image, of a function \(f:A\to B\) is the set of actual outputs:
    🔗
    \begin{equation*} \Image(f)=\{f(x):x\in A\}. \end{equation*}
    🔗
    🔗
    The notation
    🔗
    \begin{equation*} \Image(f) \end{equation*}
    🔗
    is read
    🔗
    “the image of @@PROTECTED0@@.”
    🔗
    The range always satisfies
    🔗
    \begin{equation*} \Image(f)\subseteq B. \end{equation*}
    🔗
    🔗

    Subsection 1.6.9 Domain, Codomain, and Range

    These three concepts should not be confused.
    🔗
    For
    🔗
    \begin{equation*} f:A\to B, \end{equation*}
    🔗
    we have:
    🔗
    • \(A\text{:}\) domain;
      🔗
      🔗
    • \(B\text{:}\) codomain;
      🔗
      🔗
    • \(\Image(f)\text{:}\) actual outputs.
      🔗
      🔗
    🔗
    In general,
    🔗
    \begin{equation*} \Image(f)\subseteq B, \end{equation*}
    🔗
    and equality need not hold.
    🔗
    🔗

    Subsection 1.6.10 Example of Domain, Codomain, and Range

    Define
    🔗
    \begin{equation*} f:\R\to\R,\qquad f(x)=x^2. \end{equation*}
    🔗
    The domain is
    🔗
    \begin{equation*} \R. \end{equation*}
    🔗
    The codomain is also
    🔗
    \begin{equation*} \R. \end{equation*}
    🔗
    But the range is
    🔗
    \begin{equation*} [0,\infty). \end{equation*}
    🔗
    Therefore,
    🔗
    \begin{equation*} \Image(f)\neq\R. \end{equation*}
    🔗
    🔗

    Subsection 1.6.11 Evaluating Functions

    To evaluate a function, replace its input variable by the specified value.
    🔗
    Suppose
    🔗
    \begin{equation*} f(x)=3x^2-2x+1. \end{equation*}
    🔗
    Then
    🔗
    \begin{equation*} f(2)=3(2)^2-2(2)+1=12-4+1=9. \end{equation*}
    🔗
    🔗

    Subsection 1.6.12 Worked Example: Function Evaluation

    Example 1.6.7. Evaluate a Function.

    Let
    🔗
    \begin{equation*} f(x)=2x^2-5x+3. \end{equation*}
    🔗
    Find \(f(-2)\text{.}\)
    🔗
    Manual conversion required: This table from the LaTeX source still needs to be converted to native PreTeXt.
    🔗
    Solution.
    🔗
    \begin{equation*} f(-2)=21 \end{equation*}
    🔗
    🔗
    🔗

    Subsection 1.6.13 Functions Need Not Be Given by Formulas

    A function may be described by:
    🔗
    • a formula;
      🔗
      🔗
    • a table;
      🔗
      🔗
    • a graph;
      🔗
      🔗
    • an arrow diagram;
      🔗
      🔗
    • an algorithm;
      🔗
      🔗
    • a verbal rule;
      🔗
      🔗
    • a set of ordered pairs.
      🔗
      🔗
    🔗
    The essential requirement is not the presence of a formula.
    🔗
    The essential requirement is that each input have exactly one output.
    🔗
    🔗

    Subsection 1.6.14 Functions as Sets of Ordered Pairs

    A function may be represented as a set of ordered pairs.
    🔗
    For example,
    🔗
    \begin{equation*} f=\{(1,a),(2,b),(3,b)\} \end{equation*}
    🔗
    defines a function from
    🔗
    \begin{equation*} \{1,2,3\} \end{equation*}
    🔗
    to a codomain containing \(a\) and \(b\text{.}\)
    🔗
    The first coordinates are inputs and the second coordinates are outputs.
    🔗
    🔗

    Subsection 1.6.15 When a Relation Is Not a Function

    Consider
    🔗
    \begin{equation*} R=\{(1,a),(1,b),(2,c)\}. \end{equation*}
    🔗
    The input \(1\) is associated with two distinct outputs:
    🔗
    \begin{equation*} a\qquad\text{and}\qquad b. \end{equation*}
    🔗
    Therefore \(R\) is not a function.
    🔗
    By contrast,
    🔗
    \begin{equation*} \{(1,a),(2,a),(3,a)\} \end{equation*}
    🔗
    is a function because several inputs may share the same output.
    🔗
    🔗

    Subsection 1.6.16 Exactly One Output

    The phrase “exactly one” combines two requirements:
    🔗
    1. every input has at least one output;
      🔗
      🔗
    2. no input has more than one output.
      🔗
      🔗
    🔗
    Both conditions are necessary.
    🔗
    🔗

    Subsection 1.6.17 Equality of Functions

    Two functions are equal only when they have the same domain, the same codomain, and assign the same output to every input.
    🔗
    Thus,
    🔗
    \begin{equation*} f=g \end{equation*}
    🔗
    means that the functions agree as complete mappings, not merely that their formulas look similar.
    🔗
    For example,
    🔗
    \begin{equation*} f:\R\to\R,\qquad f(x)=x^2 \end{equation*}
    🔗
    and
    🔗
    \begin{equation*} g:[0,\infty)\to\R,\qquad g(x)=x^2 \end{equation*}
    🔗
    are not the same function because their domains differ.
    🔗
    🔗

    Subsection 1.6.18 Identity Functions

    Definition 1.6.8. Identity Function.

    For a set \(A\text{,}\) the identity function on \(A\) is
    🔗
    \begin{equation*} \operatorname{id}_A:A\to A,\qquad \operatorname{id}_A(x)=x. \end{equation*}
    🔗
    🔗
    The notation
    🔗
    \begin{equation*} \operatorname{id}_A \end{equation*}
    🔗
    is read
    🔗
    “the identity on @@PROTECTED0@@.”
    🔗
    The identity function leaves every element unchanged.
    🔗
    🔗

    Subsection 1.6.19 Constant Functions

    Definition 1.6.9. Constant Function.

    A function \(f:A\to B\) is constant if there exists a fixed \(c\in B\) such that
    🔗
    \begin{equation*} f(x)=c \end{equation*}
    🔗
    for every \(x\in A\text{.}\)
    🔗
    🔗
    For example,
    🔗
    \begin{equation*} f(x)=5 \end{equation*}
    🔗
    assigns the same output to every input.
    🔗
    🔗

    Subsection 1.6.20 Inclusion Functions

    If
    🔗
    \begin{equation*} A\subseteq B, \end{equation*}
    🔗

    Subsection 1.6.25 Injective Functions

    Definition 1.6.10. Injective Function.

    A function \(f:A\to B\) is injective, or one-to-one, if
    🔗
    \begin{equation*} f(x_1)=f(x_2)\Longrightarrow x_1=x_2. \end{equation*}
    🔗
    🔗
    This means distinct inputs cannot produce the same output.
    🔗
    An equivalent statement is
    🔗
    \begin{equation*} x_1\neq x_2\Longrightarrow f(x_1)\neq f(x_2). \end{equation*}
    🔗
    🔗

    Subsection 1.6.26 Example of an Injective Function

    Consider
    🔗
    \begin{equation*} f:\R\to\R,\qquad f(x)=2x+3. \end{equation*}
    🔗
    Suppose
    🔗
    \begin{equation*} f(x_1)=f(x_2). \end{equation*}
    🔗
    Then
    🔗
    \begin{equation*} 2x_1+3=2x_2+3. \end{equation*}
    🔗
    Subtracting \(3\) gives
    🔗
    \begin{equation*} 2x_1=2x_2. \end{equation*}
    🔗
    Dividing by \(2\) gives
    🔗
    \begin{equation*} x_1=x_2. \end{equation*}
    🔗
    Therefore \(f\) is injective.
    🔗
    🔗

    Subsection 1.6.27 A Function That Is Not Injective

    Consider
    🔗
    \begin{equation*} f:\R\to\R,\qquad f(x)=x^2. \end{equation*}
    🔗
    Since
    🔗
    \begin{equation*} f(2)=4 \end{equation*}
    🔗
    and
    🔗
    \begin{equation*} f(-2)=4, \end{equation*}
    🔗
    distinct inputs produce the same output.
    🔗
    Therefore \(f\) is not injective.
    🔗
    🔗

    Subsection 1.6.28 Surjective Functions

    Definition 1.6.11. Surjective Function.

    A function \(f:A\to B\) is surjective, or onto, if every element of the codomain is the output of at least one input.
    🔗
    🔗
    Symbolically,
    🔗
    \begin{equation*} \forall y\in B,\;\exists x\in A\text{ such that }f(x)=y. \end{equation*}
    🔗
    Thus,
    🔗
    \begin{equation*} \Image(f)=B. \end{equation*}
    🔗
    🔗

    Subsection 1.6.29 Example of a Surjective Function

    Consider
    🔗
    \begin{equation*} f:\R\to\R,\qquad f(x)=x^3. \end{equation*}
    🔗
    Given any
    🔗
    \begin{equation*} y\in\R, \end{equation*}
    🔗
    choose
    🔗
    \begin{equation*} x=\sqrt[3]{y}. \end{equation*}
    🔗
    Then
    🔗
    \begin{equation*} f(x)=\left(\sqrt[3]{y}\right)^3=y. \end{equation*}
    🔗
    Therefore every real number has a preimage, and \(f\) is surjective.
    🔗
    🔗

    Subsection 1.6.30 Codomain Matters for Surjectivity

    Consider
    🔗
    \begin{equation*} f:\R\to\R,\qquad f(x)=x^2. \end{equation*}
    🔗
    This function is not surjective because negative real numbers are never outputs.
    🔗
    However,
    🔗
    \begin{equation*} g:\R\to[0,\infty),\qquad g(x)=x^2 \end{equation*}
    🔗
    is surjective.
    🔗
    Thus surjectivity depends on the specified codomain.
    🔗
    🔗

    Definition 1.6.12. Bijective Function.

    A function is bijective, or a bijection, if it is both injective and surjective.
    🔗
    🔗
    A bijection pairs the elements of the domain and codomain without omissions or repetitions.
    🔗

    🔗
    \begin{equation*} h\circ(g\circ f)=(h\circ g)\circ f. \end{equation*}

    Subsection 1.6.42 Invertibility and Bijectivity

    A function has a genuine inverse function exactly when it is bijective.

    If a function is not surjective, some elements of the codomain have no preimage, so the inverse could not assign them outputs.
    🔗
    Thus bijectivity is precisely the condition required for invertibility.
    🔗
    🔗

    A formula alone does not completely determine a function.

    The range consists only of outputs actually obtained.
    🔗
    They need not be equal.
    🔗
    🔗

    A function must be bijective to possess an inverse function between its full domain and codomain.

    🔗

    🔗
    \begin{equation*} f^{-1}(x) \end{equation*}

    🔗
    \begin{equation*} \frac1{f(x)} \end{equation*}
    🔗
    usually mean different things.

    🔗

    The expression
    🔗
    \begin{equation*} (g\circ f)(x) \end{equation*}
    🔗
    means
    🔗
    \begin{equation*} g(f(x)). \end{equation*}
    🔗

    Remark 1.6.45. Chapter Connection.

    Functions build directly on relations from Section 1.5 and become foundational throughout the rest of mathematics. Calculus studies rates of change and accumulation of functions; linear algebra studies linear transformations; probability studies random variables; statistics studies models and estimators; topology and analysis rely heavily on images and preimages; and abstract algebra studies functions preserving algebraic structure.
