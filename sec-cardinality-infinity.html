    Remark 1.9.1. Prerequisites.

    Familiarity with sets from Section 1.4, functions from Section 1.6, and proof techniques from Section 1.8.

    🔗

    Remark 1.9.2. Learning Objectives.

    By the end of this section, the reader should be able to:

      🔗

      🔗

      🔗
    • understand why countable unions of countable sets are countable;
      🔗
      🔗
    • explain why \(\Q\) is countable;
      🔗
      🔗
    • distinguish density from cardinality;
      🔗
      🔗
    • understand Cantor’s diagonal argument;
      🔗
      🔗
    • explain why \(\R\) is uncountable;
      🔗
      🔗
    • compare infinite cardinalities;

      🔗

    Subsection 1.9.1 What Does It Mean for a Set to Have a Size?

    For a finite set, the idea of size is familiar.
    🔗
    If
    🔗
    \begin{equation*} A=\{a,b,c,d\}, \end{equation*}
    🔗
    then \(A\) contains four elements.
    🔗
    We write
    🔗
    \begin{equation*} |A|=4. \end{equation*}
    🔗
    The notation
    🔗
    \begin{equation*} |A| \end{equation*}
    🔗
    is read
    🔗
    “the cardinality of @@PROTECTED0@@”
    🔗
    or
    🔗
    “the number of elements of @@PROTECTED0@@.”
    🔗
    For finite sets, cardinality simply counts the elements.
    🔗
    The concept becomes much more interesting for infinite sets.
    🔗
    🔗

    Subsection 1.9.2 Cardinality

    Definition 1.9.3. Cardinality.

    The cardinality of a set is a mathematical description of the size of that set.
    🔗
    For finite sets, cardinality is the number of elements in the set.
    🔗
    🔗
    For example,
    🔗
    \begin{equation*} A=\{2,4,6,8,10\} \end{equation*}
    🔗
    has cardinality
    🔗
    \begin{equation*} |A|=5. \end{equation*}
    🔗
    Similarly,
    🔗
    \begin{equation*} |\varnothing|=0. \end{equation*}
    🔗
    🔗

    Subsection 1.9.3 Comparing Sets Without Counting

    Suppose one has two collections of objects and wants to determine whether they have the same size.
    🔗
    Instead of counting both collections, one may pair each object from the first collection with exactly one object from the second.
    🔗
    If every object is paired once and no object is left over, the two collections have the same size.
    🔗
    This idea extends naturally to infinite sets.
    🔗
    🔗

    Subsection 1.9.4 Equal Cardinality

    Definition 1.9.4. Equal Cardinality.

    Two sets \(A\) and \(B\) have the same cardinality if there exists a bijection
    🔗
    \begin{equation*} f:A\to B. \end{equation*}
    🔗
    🔗
    We may write
    🔗
    \begin{equation*} |A|=|B|. \end{equation*}
    🔗
    Thus cardinality is fundamentally connected to bijective functions.
    🔗
    🔗

    Subsection 1.9.5 Worked Example: Equal Finite Cardinality

    Example 1.9.5. Compare Two Finite Sets.

    Let
    🔗
    \begin{equation*} A=\{a,b,c\},\qquad B=\{4,7,9\}. \end{equation*}
    🔗
    Define
    🔗
    \begin{equation*} f(a)=4,\qquad f(b)=7,\qquad f(c)=9. \end{equation*}
    🔗

    🔗
    Therefore \(f\) is bijective.
    🔗
    Solution.
    🔗
    \begin{equation*} |A|=|B|=3 \end{equation*}
    🔗
    🔗
    🔗

    Subsection 1.9.6 Finite Sets

    Definition 1.9.6. Finite Set.

    A set \(A\) is finite if either \(A=\varnothing\) or there exists some positive integer \(n\) such that
    🔗
    \begin{equation*} |A|=n. \end{equation*}
    🔗
    🔗
    Equivalently, a nonempty finite set can be placed in bijection with
    🔗
    \begin{equation*} \{1,2,\ldots,n\} \end{equation*}
    🔗
    for some positive integer \(n\text{.}\)
    🔗
    🔗

    Subsection 1.9.7 Infinite Sets

    Definition 1.9.7. Infinite Set.

    A set is infinite if it is not finite.
    🔗
    🔗
    Examples include
    🔗
    \begin{equation*} \N,\qquad \Z,\qquad \Q,\qquad \R,\qquad \C. \end{equation*}
    🔗
    However, these infinite sets do not all have the same cardinality.
    🔗
    Understanding this fact is one of the central ideas of set theory.
    🔗
    🔗

    Subsection 1.9.8 A Strange Property of Infinite Sets

    For finite sets, a proper subset always has strictly smaller cardinality.
    🔗
    For example,
    🔗
    \begin{equation*} \{1,2\}\subsetneq\{1,2,3\} \end{equation*}
    🔗
    and
    🔗
    \begin{equation*} 2<3. \end{equation*}
    🔗
    Infinite sets behave differently.
    🔗
    Consider
    🔗
    \begin{equation*} \N=\{1,2,3,\ldots\} \end{equation*}
    🔗
    and the set of positive even integers
    🔗
    \begin{equation*} E=\{2,4,6,\ldots\}. \end{equation*}
    🔗
    Clearly,
    🔗
    \begin{equation*} E\subsetneq\N. \end{equation*}
    🔗
    Yet the function
    🔗
    \begin{equation*} f:\N\to E,\qquad f(n)=2n \end{equation*}
    🔗
    is a bijection.
    🔗
    Therefore,
    🔗
    \begin{equation*} |\N|=|E|. \end{equation*}
    🔗
    An infinite set can have the same cardinality as one of its proper subsets.
    🔗
    🔗

    Subsection 1.9.9 Dedekind-Infinite Behavior

    This phenomenon can be used as one characterization of infinite sets in standard set theory.
    🔗
    A set may be infinite while still being pairable one-to-one with a proper subset of itself.
    🔗
    This is fundamentally different from finite sets.
    🔗
    🔗

    Subsection 1.9.10 Countably Infinite Sets

    Definition 1.9.8. Countably Infinite Set.

    A set \(A\) is countably infinite if there exists a bijection
    🔗
    \begin{equation*} f:\N\to A. \end{equation*}
    🔗
    🔗
    Intuitively, the elements of \(A\) can be arranged in an infinite list:
    🔗
    \begin{equation*} a_1,a_2,a_3,\ldots. \end{equation*}
    🔗
    Every element must appear somewhere on the list.
    🔗
    🔗

    Subsection 1.9.11 The Cardinal \(\aleph_0\)

    The symbol
    🔗
    \begin{equation*} \aleph_0 \end{equation*}
    🔗
    uses the Hebrew letter aleph.
    🔗
    It is pronounced
    🔗
    “aleph-null”
    🔗
    or
    🔗
    “aleph-zero.”
    🔗
    The subscript \(0\) is read “zero” or sometimes “naught.”
    🔗

    Definition 1.9.9. Aleph-Zero.

    The cardinality of the natural numbers is denoted
    🔗
    \begin{equation*} |\N|=\aleph_0. \end{equation*}
    🔗
    🔗
    The cardinal \(\aleph_0\) represents the size of every countably infinite set.
    🔗
    🔗

    Subsection 1.9.12 Countable Sets

    The word countable is commonly used slightly more broadly.
    🔗

    Definition 1.9.10. Countable Set.

    A set is countable if it is finite or countably infinite.
    🔗
    🔗
    Thus every finite set is countable, and every set with cardinality \(\aleph_0\) is countable.
    🔗
    🔗

    Subsection 1.9.13 Infinite Subsets of Countable Sets

    An infinite subset of a countable set is itself countably infinite.
    🔗
    For example, the prime numbers
    🔗
    \begin{equation*} \{2,3,5,7,11,\ldots\} \end{equation*}
    🔗
    form an infinite subset of \(\N\text{.}\)
    🔗
    Therefore the prime numbers are countably infinite.
    🔗
    This does not mean there are “as many primes as integers” in terms of density or frequency.
    🔗
    It means there is a bijection between the two sets.
    🔗
    🔗

    Subsection 1.9.14 The Integers Are Countable

    At first, \(\Z\) may seem larger than \(\N\) because it contains positive integers, negative integers, and zero.
    🔗
    Nevertheless,
    🔗
    \begin{equation*} |\Z|=|\N|. \end{equation*}
    🔗
    One way to list the integers is
    🔗
    \begin{equation*} 0,1,-1,2,-2,3,-3,\ldots. \end{equation*}
    🔗
    Every integer eventually appears in this list.
    🔗
    Therefore \(\Z\) is countably infinite.
    🔗
    🔗

    Subsection 1.9.15 A Bijection from \(\N\) to \(\Z\)

    A formal bijection may be defined by
    🔗
    \begin{equation*} f(n)= \begin{cases} \dfrac n2,&n\text{ even},\\[4pt] -\dfrac{n-1}{2},&n\text{ odd}. \end{cases} \end{equation*}
    🔗
    With \(\N=\{1,2,3,\ldots\}\text{,}\) this gives
    🔗
    \begin{equation*} f(1)=0,\quad f(2)=1,\quad f(3)=-1,\quad f(4)=2,\quad f(5)=-2,\ldots \end{equation*}
    🔗
    Every integer occurs exactly once.
    🔗
    🔗

    Subsection 1.9.16 Worked Example: Positive Multiples of Three

    Example 1.9.11. Show a Proper Subset of \(\N\) Has the Same Cardinality.

    Let
    🔗
    \begin{equation*} M=\{3,6,9,12,\ldots\}. \end{equation*}
    🔗
    Define
    🔗
    \begin{equation*} f:\N\to M,\qquad f(n)=3n. \end{equation*}
    🔗
    Manual conversion required: This table from the LaTeX source still needs to be converted to native PreTeXt.
    🔗
    Solution.
    🔗
    \begin{equation*} |\N|=|M|=\aleph_0 \end{equation*}
    🔗
    🔗
    🔗

    Subsection 1.9.17 Cartesian Products and Countability

    Consider
    🔗
    \begin{equation*} \N\times\N. \end{equation*}
    🔗
    Its elements are ordered pairs
    🔗
    \begin{equation*} (m,n) \end{equation*}
    🔗
    of natural numbers.
    🔗
    It may initially appear that two coordinates should produce a larger infinity.
    🔗
    Surprisingly,
    🔗
    \begin{equation*} |\N\times\N|=\aleph_0. \end{equation*}
    🔗
    Thus \(\N\times\N\) is countably infinite.
    🔗
    🔗

    Subsection 1.9.18 Diagonal Enumeration of \(\N\times\N\)

    The ordered pairs can be listed diagonally.
    🔗
    For example:
    🔗
    \begin{equation*} (1,1), \end{equation*}
    🔗
    then
    🔗
    \begin{equation*} (1,2),(2,1), \end{equation*}
    🔗
    then
    🔗
    \begin{equation*} (1,3),(2,2),(3,1), \end{equation*}
    🔗
    then
    🔗
    \begin{equation*} (1,4),(2,3),(3,2),(4,1), \end{equation*}
    🔗
    and so on.
    🔗
    Every ordered pair appears on exactly one diagonal corresponding to a fixed value of
    🔗
    \begin{equation*} m+n. \end{equation*}
    🔗
    Thus all pairs can be placed into a single sequence.
    🔗
    🔗

    Subsection 1.9.19 Finite Cartesian Powers of \(\N\)

    The same idea extends to higher finite dimensions.
    🔗
    For every positive integer \(k\text{,}\)
    🔗
    \begin{equation*} |\N^k|=\aleph_0. \end{equation*}
    🔗
    Thus
    🔗
    \begin{equation*} \N,\qquad \N^2,\qquad \N^3,\qquad \ldots \end{equation*}
    🔗
    all have the same cardinality.
    🔗
    This is another example of how infinite cardinality differs dramatically from finite size.
    🔗
    🔗

    Subsection 1.9.20 Countable Unions

    Suppose
    🔗
    \begin{equation*} A_1,A_2,A_3,\ldots \end{equation*}
    🔗
    are countable sets.
    🔗
    Then their union
    🔗
    \begin{equation*} \bigcup_{n=1}^{\infty}A_n \end{equation*}
    🔗
    is countable.
    🔗
    This principle is often summarized as:
    🔗
    \begin{importantbox} A countable union of countable sets is countable. \end{importantbox}
    🔗
    This result is extremely useful when proving that complicated sets are still countable.
    🔗
    🔗

    Subsection 1.9.21 Why Countable Unions Remain Countable

    Imagine arranging each countable set as a row:
    🔗
    \begin{equation*} \begin{array}{cccc} a_{11}&a_{12}&a_{13}&\cdots\\ a_{21}&a_{22}&a_{23}&\cdots\\ a_{31}&a_{32}&a_{33}&\cdots\\ \vdots&\vdots&\vdots& \end{array} \end{equation*}
    🔗
    The entries may be traversed diagonally in the same way as \(\N\times\N\text{.}\)
    🔗
    If duplicates occur, simply omit repeated entries.
    🔗
    This produces a single list containing every element of the union.
    🔗
    🔗

    Subsection 1.9.22 The Rational Numbers

    Recall that every rational number can be written as
    🔗
    \begin{equation*} \frac pq \end{equation*}
    🔗
    where
    🔗
    \begin{equation*} p\in\Z,\qquad q\in\N. \end{equation*}
    🔗
    Thus the rational numbers arise from pairs
    🔗
    \begin{equation*} (p,q)\in\Z\times\N. \end{equation*}
    🔗
    Since \(\Z\) and \(\N\) are countable, their Cartesian product is countable.
    🔗
    This suggests that \(\Q\) is countable.
    🔗
    🔗

    Subsection 1.9.23 The Rational Numbers Are Countable

    Every rational number is represented by at least one pair
    🔗
    \begin{equation*} (p,q)\in\Z\times\N. \end{equation*}
    🔗
    Since
    🔗
    \begin{equation*} |\Z\times\N|=\aleph_0, \end{equation*}
    🔗
    the collection of such pairs is countable.
    🔗
    Different pairs may represent the same rational number:
    🔗
    \begin{equation*} \frac12=\frac24=\frac36. \end{equation*}
    🔗
    Removing these duplicates does not make the set uncountable.
    🔗
    Therefore,
    🔗
    \begin{equation*} |\Q|=\aleph_0. \end{equation*}
    🔗
    🔗

    Subsection 1.9.24 A Surprising Consequence

    The rational numbers are distributed throughout the real number line.
    🔗
    Between any two distinct real numbers there exists a rational number.
    🔗
    Nevertheless,
    🔗
    \begin{equation*} |\Q|=|\N|. \end{equation*}
    🔗
    Thus geometric density and cardinality are different concepts.
    🔗
    🔗

    Subsection 1.9.25 Density versus Cardinality

    A subset \(D\subseteq\R\) is dense in @@PROTECTED1@@ if every open interval contains an element of \(D\text{.}\)

    🔗
    The rational numbers are dense in \(\R\text{.}\)
    🔗
    The irrational numbers are also dense in \(\R\text{.}\)
    🔗
    Density describes how a set is distributed.
    🔗
    Cardinality describes how many elements it contains.
    🔗
    These ideas should not be confused.

    Subsection 1.9.26 Uncountable Sets

    Definition 1.9.13. Uncountable Set.

    A set is uncountable if it is not countable.
    🔗
    🔗
    An uncountable set cannot be placed into a finite or infinite sequence that lists every element.
    🔗
    The real numbers provide the most important introductory example.
    🔗
    🔗

    Subsection 1.9.27 Can the Real Numbers Be Listed?

    Suppose one attempts to list all real numbers in the interval
    🔗
    \begin{equation*} (0,1). \end{equation*}
    🔗
    If this were possible, the list might look like
    🔗
    \begin{equation*} \begin{aligned} x_1&=0.d_{11}d_{12}d_{13}d_{14}\ldots,\\ x_2&=0.d_{21}d_{22}d_{23}d_{24}\ldots,\\ x_3&=0.d_{31}d_{32}d_{33}d_{34}\ldots,\\ &\phantom{=}~\vdots \end{aligned} \end{equation*}

    where each \(d_{ij}\) is a decimal digit.
    🔗
    Cantor’s diagonal argument shows that no such complete list can exist.
    🔗
    🔗

    Subsection 1.9.28 Cantor’s Diagonal Argument

    Assume for contradiction that every real number in \((0,1)\) appears in a list:
    🔗
    \begin{equation*} x_1,x_2,x_3,\ldots. \end{equation*}
    🔗
    Construct a new real number
    🔗
    \begin{equation*} y=0.c_1c_2c_3\ldots \end{equation*}
    🔗
    by choosing \(c_n\) so that it differs from the \(n\)-th decimal digit of \(x_n\text{.}\)
    🔗
    For example, one may define
    🔗
    \begin{equation*} c_n= \begin{cases} 1,&d_{nn}\neq1,\\ 2,&d_{nn}=1. \end{cases} \end{equation*}
    🔗
    Then \(y\) differs from \(x_1\) in the first digit, from \(x_2\) in the second digit, from \(x_3\) in the third digit, and so on.
    🔗
    Therefore
    🔗
    \begin{equation*} y\neq x_n \end{equation*}
    🔗
    for every \(n\text{.}\)
    🔗
    But \(y\in(0,1)\text{,}\) so the supposed list omitted a real number.
    🔗
    This is a contradiction.
    🔗
    🔗

    Subsection 1.9.29 The Real Numbers Are Uncountable

    Cantor’s argument proves that
    🔗
    \begin{equation*} (0,1) \end{equation*}
    🔗
    is uncountable.
    🔗
    Since
    🔗
    \begin{equation*} (0,1)\subseteq\R, \end{equation*}
    🔗
    the real numbers must also be uncountable.
    🔗
    Therefore,
    🔗
    \begin{equation*} |\R|>\aleph_0. \end{equation*}
    🔗
    There are strictly more real numbers than natural numbers.
    🔗
    🔗

    Subsection 1.9.30 Why the Diagonal Construction Works

    The construction does not merely produce a number different from many entries.
    🔗
    It produces a number different from every entry.
    🔗
    For each \(n\text{,}\)
    🔗
    \begin{equation*} y \end{equation*}
    🔗
    differs from
    🔗
    \begin{equation*} x_n \end{equation*}
    🔗
    specifically at the \(n\)-th decimal place.
    🔗
    Therefore no \(x_n\) can equal \(y\text{.}\)
    🔗
    🔗

    Subsection 1.9.31 Decimal Representation Subtlety

    Some real numbers have two decimal representations.
    🔗
    For example,
    🔗
    \begin{equation*} 0.5000\ldots=0.4999\ldots. \end{equation*}
    🔗
    When presenting a rigorous diagonal argument, one avoids this ambiguity by choosing constructed digits from a restricted set, such as \(1\) and \(2\text{,}\) rather than using \(9\text{.}\)
    🔗
    This ensures that the constructed decimal does not end in an infinite string of \(9\)’s.

    Subsection 1.9.32 Not All Infinities Are Equal

    We have now seen
    🔗
    \begin{equation*} |\N|=|\Z|=|\Q|=\aleph_0 \end{equation*}
    🔗
    but
    🔗
    \begin{equation*} |\R|>\aleph_0. \end{equation*}
    🔗
    Thus there are different sizes of infinity.
    🔗
    This was one of Georg Cantor’s most important discoveries.
    🔗
    🔗

    Subsection 1.9.33 The Continuum

    The cardinality of the real numbers is commonly denoted
    🔗
    \begin{equation*} \mathfrak c. \end{equation*}
    🔗
    The symbol
    🔗
    \begin{equation*} \mathfrak c \end{equation*}
    🔗
    is a lowercase \(c\) written in Fraktur type and is read

    “the cardinality of the continuum”

    or simply
    🔗
    “the continuum.”
    🔗
    Thus,
    🔗
    \begin{equation*} |\R|=\mathfrak c. \end{equation*}
    🔗
    🔗

    Subsection 1.9.34 Intervals Have the Same Cardinality as \(\R\)

    A bounded interval can have the same cardinality as the entire real line.
    🔗
    For example,
    🔗
    \begin{equation*} (0,1) \end{equation*}
    🔗
    and
    🔗
    \begin{equation*} \R \end{equation*}
    🔗

    \begin{equation*} \left(-\frac{\pi}{2},\frac{\pi}{2}\right), \end{equation*}

    Hence,

    \begin{equation*} |(0,1)|=|\R|=\mathfrak c. \end{equation*}

    Subsection 1.9.35 Bounded Length Does Not Determine Cardinality

    The interval
    🔗
    \begin{equation*} (0,1) \end{equation*}
    🔗
    has finite geometric length \(1\text{.}\)
    🔗
    The real line
    🔗
    \begin{equation*} \R \end{equation*}
    🔗
    has infinite geometric extent.

    Yet they have the same cardinality.

    🔗
    \begin{equation*} \mathfrak c. \end{equation*}

    The notation
    🔗
    \begin{equation*} |A|\leq|B| \end{equation*}
    🔗
    can be interpreted as saying that there exists an injective function
    🔗
    \begin{equation*} f:A\to B. \end{equation*}
    🔗
    This means that the elements of \(A\) can be embedded into \(B\) without collisions.

    If
    🔗
    \begin{equation*} |A|\leq|B| \end{equation*}

    🔗
    \begin{equation*} |B|\leq|A|, \end{equation*}

    \begin{equation*} h:A\to B. \end{equation*}

    🔗
    \begin{equation*} |A|=|B|. \end{equation*}
    🔗
    \end{theorem}

    🔗

    The Cantor--Bernstein--Schröder theorem then guarantees equal cardinality.

    🔗

    🔗

    🔗

    🔗

    \begin{theorem}[Cantor’s Theorem] For every set \(A\text{,}\)

    \begin{equation*} |A|<|\mathcal P(A)|. \end{equation*}
    🔗
    \end{theorem}
    🔗
    In other words, there is no bijection from a set to its own power set.

    Subsection 1.9.55 Section Connections

    Remark 1.9.45. Chapter Connection.

    Cardinality combines set theory, functions, logic, and proof methods from the earlier sections of Chapter 0. Countability becomes important in number theory, discrete mathematics, probability, topology, and analysis. Uncountability is central to the structure of the real numbers and later motivates deeper questions in axiomatic set theory. Power-set arguments and Cantor’s theorem also reappear in mathematical logic and foundations.
